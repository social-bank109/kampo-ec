# VISTA Wellness 画像差し替えガイド

## 置き場所と反映方法

1. 画像を **`public/images/vista/`** に、下表の**ファイル名どおり**に置く（GitHub の場合：ブランチ `claude/implement-design-system-m4j2b` → `public/images/vista/` → *Add file → Upload files*）
2. コミットすると Vercel が再ビルドし、**コードの変更なしで自動的に表示が切り替わります**（ビルド時にファイルの有無を判定）
3. 画像が無いあいだは、背景色＋控えめな模様＋用途ラベルのプレースホルダーが表示されます（壊れた画像アイコンは出ません）

ファイル名やサイズを変えたい場合は `src/config/vistaAssets.ts` を編集してください。

## 素材の注意事項（必ず確認）

- **肌の写真**：症例写真・ビフォーアフターは医療広告ガイドライン上の制約が大きいため使用しない。イメージ写真である旨を前提に、過度な加工で「効果」を連想させないこと
- **人物**：モデルリリース（肖像の使用許諾）を取得済みの素材のみ。医師役のモデルを使う場合、**実在の提携医療機関・医師と誤認させない**（白衣の人物＋実在クリニック名の併記等は避ける）
- **漢方の画像**：メーカーの製品パッケージ写真・ロゴは使用許諾が無い限り使わない。生薬や抽象的なイメージを推奨（未配備時のイラストは「イメージ」と明記した抽象表現）
- 既存の `public/images/kampo/*.jpg`（旧サイト用）は権利関係を確認のうえ、流用する場合は上表のファイル名で `public/images/vista/` に置き直す
- 外部URL（Unsplash等）の直接参照は禁止。必ずリポジトリに保存し、ライセンスを記録する
- 生成AI画像を使う場合は、その旨と利用規約上の商用可否を記録し、肌の症状・医師・製品の写真として誤認させないこと
